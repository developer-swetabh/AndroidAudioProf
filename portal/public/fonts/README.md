# Self-hosted fonts

Variable `wght` axis, `latin` and `latin-ext` subsets only, copied from the
Fontsource packages (`@fontsource-variable/inter`, `@fontsource-variable/outfit`,
`@fontsource-variable/jetbrains-mono`, all 5.3.0). The `@font-face` rules are
inline in `portal/index.html`. All three fonts are under the SIL Open Font
License 1.1 (see the `OFL-*.txt` files). The version is part of the path so
`/fonts/*` can be cached as immutable; use a new folder when upgrading.
